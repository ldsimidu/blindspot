# Tasks de melhoria

Cada task deve apontar para um achado, definir escopo mínimo, critérios de aceite, evidência de validação e dependências. Mudanças de UI que alterem fluxo, contrato, dados, API ou comportamento devem passar pelo Architecture Gate.

Use `task-template.md` para novas tasks e mantenha separadas as melhorias de compreensão, estados, acessibilidade, responsividade, funcionalidade e acabamento visual.
