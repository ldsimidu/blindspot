# Project Compliance Assurance

Leia o perfil do projeto e `optional/project-compliance-assurance/contract.md`. Use esta skill quando a mudança envolver dados pessoais, IA com dados de pessoas, retenção, exportação, terceiros, analytics, cookies, upload, logs, backups, transferência internacional ou outra obrigação declarada pelo projeto.

Use `COMPLIANCE-REVIEW-TEMPLATE.md`. Para LGPD, use a fonte oficial consolidada da Lei nº 13.709/2018 e orientações vigentes da ANPD, registrando URL e data de consulta. Não conclua que uma base legal é válida nem que o sistema está em conformidade: sinalize a validação pelo responsável competente.

Bloqueie casos sem finalidade, responsável, destino de dados, retenção/descarte ou transparência definidos, e escale dados sensíveis, crianças/adolescentes, incidente ou dúvida jurídica material. Não exponha dados pessoais ou segredos, nem envie dados a serviços externos como efeito da revisão.

A skill produz evidência para o Architecture Gate, security assurance, handoff e release; não autoriza rede, escrita externa, comunicação à autoridade ou decisão jurídica.
