# Project Release Management

Leia política, Release Ledger, tasks, handoffs e decisões relevantes. Crie ou atualize somente registros de release autorizados. Antes de `released`, confirme aprovação explícita e evidência. Não publique, crie tags, altere versões ou faça deploy.
