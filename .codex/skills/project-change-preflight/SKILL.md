# Project Change Preflight

Leia o perfil, mapa de contexto quando houver, contratos afetados e estratégia de verificação. Produza `PREFLIGHT-TEMPLATE.md` com fatos, lacunas, impacto, riscos, reversibilidade e verificações. Não implemente, crie task ou aprove a arquitetura; encaminhe para o Architecture Gate quando o recorte estiver suficiente.
