# Checagem de frescor do mapa

Antes de reutilizar um mapa para alteração material:

1. confirme o escopo e a data de atualização;
2. compare os paths da mudança com as fontes registradas;
3. revise alterações recentes, contratos e configuração que possam afetar a conclusão;
4. marque o mapa como `atual`, `a revisar` ou `desatualizado`;
5. atualize o mapa ou registre no brief a limitação encontrada.

Não use ausência de alteração conhecida como prova de que o mapa cobre todo o comportamento.
